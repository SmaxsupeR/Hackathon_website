# Namu — тренажёр корейского языка

Бесплатное Android-приложение для изучения корейской лексики: личные словари, карточки и интервальные повторения. Без рекламы, подписок и регистрации; все данные хранятся на устройстве и работают без интернета.

«Namu» (나무, «дерево») — рабочее название.

## Что уже работает

Этап 1 из технического задания («Рабочее ядро») и часть этапа 2:

- **Словари** — создание, переименование, цвет, избранное, пауза, архив, дублирование, удаление.
- **Слова** — два обязательных поля (корейское слово и перевод), несколько значений через `;`, транскрипция, пример, часть речи, теги, заметки. Быстрое добавление подряд, вставка из буфера по нажатию, предупреждение о дубликатах, поиск.
- **Обучение в три этапа** — знакомство со словом, затем выбор из вариантов и ввод ответа без подсказок; только после верного ответа слово попадает в расписание повторений FSRS. Два направления (한 → перевод и перевод → 한) учатся и планируются отдельно. Ошибки ведут к дополнительной тренировке, но не больше трёх раз за занятие. Подробно: [docs/learning.md](docs/learning.md).
- **Проверка ответов** — корейский с Unicode-нормализацией хангыля и подсветкой различий; перевод — с учётом всех значений, ё/е и одной опечатки.
- **Импорт и экспорт** — CSV, TSV и вставка списка с предпросмотром, поиском дубликатов и отчётом об ошибках; полная резервная копия в JSON и восстановление из неё.
- **Статистика** — слова по стадиям (не начаты / изучаются / запомнены), узнавание и воспроизведение отдельно, активность, прогноз повторений, трудные слова.
- **Озвучивание** через системный синтез речи Android с проверкой наличия корейского голоса.
- Светлая и тёмная тема, интерфейс на русском и английском.

Ещё не сделано: аудирование как отдельный режим, рукописный ввод, смешанная тренировка, работа над ошибками, подсказки, уведомления, грамматика, стартовый словарь, онбординг, аналитика, корейский язык интерфейса.

## Устройство проекта

```
src/core/      логика без интерфейса и базы: хангыль, проверка ответов, импорт, планировщик
src/db/        схема SQLite с миграциями и все запросы
src/services/  озвучивание, файлы
src/state/     настройки
src/ui/        тема, строки интерфейса, общие компоненты
src/app/       экраны (Expo Router)
```

Стек: React Native, Expo, TypeScript, Expo Router, SQLite, Zustand, ts-fsrs.

## Разработка

```bash
npm install
npm test            # тесты логики и базы данных
npm run typecheck
npx expo start      # запуск в режиме разработки
```

## Сборка APK

Нужны Node 22, JDK 17 и 21, Android SDK (platform 35, build-tools 35).

```bash
./scripts/build-apk.sh    # результат: build/namu.apk
```

APK подписывается отладочным ключом: его можно установить на телефон, но для публикации в Google Play нужен собственный ключ подписи.
